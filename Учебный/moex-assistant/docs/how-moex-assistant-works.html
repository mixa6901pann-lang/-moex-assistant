Как работает MOEX Assistant

Версия: 2026-06-17 | Авторы: Миша + Claude (Anthropic)

1. Общая идея

MOEX Assistant — это автоматизированный аналитик российского фондового рынка (Мосбиржа). Он собирает рыночные данные, анализирует их с помощью нейросетей, принимает торговые решения в виртуальном портфеле, ведёт дневник предсказаний и предупреждает о геополитических рисках.

2. Архитектура

MOEX API  →  Ядро (core/)  →  Агенты  →  Веб / VK / Бумажный портфель
RSS ленты  →  moex.py      → TradingAgent
Geo-сканер  →  db.py        → GeoRiskAgent
              llm.py        → NewsSentimentAgent
              codeact.py

4. ReAct-цикл TradingAgent (18:00)

Главное событие дня. Агент работает по циклу Наблюдение → Мышление → Действие → Решение:

  1. Получает системную инструкцию с живым портфелем и котировками
  2. Решает, какие данные нужны
  3. Вызывает инструменты:
    • get_price("SBER") — цена и свечи
    • get_indicator("SBER", "rsi") — RSI, MACD, ADX
    • get_news("SBER") — новости
    • get_georisk() — геополитика
    • search_web("SBER санкции") — поиск по RSS
    • execute_python("...") — математика (корреляция и т.д.)
  4. После 1–5 итераций выдаёт JSON-решение: action, confidence, reasoning, price
Пример решения: action: wait, ticker: SBER, confidence: 95, reasoning: "Нет чёткого направления, тренд боковой", price: 320.37

5. Бумажная торговля

  • Счёт: 50 000 ₽ (виртуальный)
  • Лимит позиций: 5 одновременно
  • Размер сделки: до 2% от капитала
  • Стоп-лосс: 2×ATR
  • Таймаут: закрытие через 7 дней

6. LLM-провайдеры и fallback

При исчерпании кредитов система автоматически переходит на Ollama и логирует предупреждение. После пополнения — снова Claude.

7. GeoRisk — геополитический стоп

Сканер оценивает риск по шкале 0–10:

  • 0–3: низкий — торговля разрешена
  • 4–6: умеренный — осторожность
  • 7–10: критический — ВСЕ позиции закрываются, новые не открываются

Источники: ТАСС, Lenta.ru, РИА Новости. Ключевые слова: санкции, война, Иран, нефть, газ, СВО.

8. CodeAct — математика от LLM

LLM может писать Python-код для расчётов в изолированной песочнице. Разрешены: numpy, scipy, pandas, math, statistics.

import numpy as np
from scipy import stats
corr, p = stats.pearsonr(sber_prices, gazp_prices)
print(f"Корреляция: {corr:.4f}")

11. Безопасность

  • Whitelist — только 33 разрешённых тикера
  • GeoRisk ≥ 7 — аварийное закрытие всех позиций
  • Бумажная торговля — никаких реальных денег
  • CodeAct sandbox — нельзя открывать файлы, выходить в сеть
  • Макс 5 позиций — защита от переконцентрации
