## Проект

Telegram-бот — аналитик Московской биржи. Бот **не торгует сам** — только собирает данные, считает индикаторы и предлагает идеи. Решение принимает человек.

Фазы работы:
1. Утро (10:00) — скачивает цены 25 акций, считает индикаторы, выдаёт топ идей
2. День (каждые 15 мин) — следит за утренним списком, шлёт алерты при аномалиях
3. Вечер (19:00) — сводка за день

Компоненты:
- `core/moex.py` — данные с Мосбиржи (бесплатно, без API-ключа)
- `strategies/indicators.py` — 7 индикаторов: RSI, MACD, ATR, Bollinger, SMA, VWAP, Volume ratio
- `strategies/risk.py` — контроль рисков: макс 2% на сделку, автостоп-лосс через ATR, диверсификация, мин. риск/прибыль 1.5:1
- `core/db.py` — SQLite: история цен, журнал сделок, результаты скринера
- `core/analyzer.py` — подключение к Claude для объяснений простым языком
- `bot/telegram_bot.py` — команды: /screener, /ticker, /trade, /positions, /close
- `main.py` — расписание и запуск
